# hypothesis-benchmark
Бенчмарк генерации гипотез и выводов в задачах анализа данных

## архитектура

`parser.py` собирает ноутбуки и данные с kaggle. результаты сохраняются в папке `data/`.

```text
hypothesis-benchmark/
├── parser.py
├── requirements.txt
└── data/
    ├── notebooks/
    │   └── соревнование/автор/ноутбук/
    │       ├── notebook.ipynb
    │       └── metadata.json
    ├── competitions/
    │   └── соревнование/
    │       ├── metadata.json
    │       └── *.csv
    ├── datasets/
    │   └── автор/датасет/
    │       ├── metadata.json
    │       └── *.csv
    └── review.json
```

### как работает парсер

в режиме `auto` парсер ищет ноутбуки по соревнованию, проверяет язык, текстовые пояснения и наличие анализа данных, затем скачивает подходящие ноутбуки с результатами выполнения, метаданные и csv.

`manual` позволяет скачать конкретный ноутбук без фильтрации, `review` создает отчет о содержимом уже скачанных ноутбуков.

ноутбуки и данные пока хранятся локально.
